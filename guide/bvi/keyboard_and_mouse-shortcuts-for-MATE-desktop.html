Introduction

This reference lists keyboard and mouse shortcuts for the MATE desktop environment, covering the Marco window manager and the MATE Terminal application. Marco handles how windows behave: moving, resizing, tiling, minimizing, and switching between them, as well as switching between virtual desktops known as workspaces. MATE Terminal is the default terminal application, and its shortcuts cover tabs, searching, zooming, and copy and paste.

Each entry describes what the shortcut does and why someone would want to use it, followed by the exact key combination needed to trigger it. The list is organized into four sections: mouse actions on the window titlebar, global keyboard shortcuts that work anywhere on the desktop, shortcuts that apply to the currently focused window, and terminal-specific shortcuts.

Note on terminology: Super refers to the key sometimes labeled with a Windows logo, and Alt refers to the key labeled Alt, sometimes called Option on other keyboard layouts. Where a shortcut is described as a run command slot, this means the key combination triggers a custom, user-assigned action rather than a fixed, built‑in one, so the actual result may vary between systems.

A section on building muscle memory follows the shortcut list, with practical guidance on how to learn and retain these shortcuts over time rather than simply memorizing them all at once.

Marco Window Manager: Mouse Actions on Titlebar

  • Toggle maximize. To quickly maximize or restore a window without locating a button: double-click the titlebar
  • Lower the window behind others. To send a window to the back without minimizing it: middle-click the titlebar
  • Open the window menu. To access move, resize, and workspace options with the mouse: right-click the titlebar

Marco Window Manager: Global Keyboard Shortcuts

  • Open the main menu. To launch applications without a mouse: Alt + F1
  • Open the run dialog. To quickly launch a command or application by typing its name: Alt + F2
  • Switch between open windows. To cycle forward through your open windows: Alt + Tab
  • Switch between open windows in reverse. To cycle backward instead: Alt + Shift + Tab
  • Cycle through windows in the same application group. For when one app has multiple windows open: Alt + F6
  • Switch window group. As an alternate way to cycle windows within the current application: Alt + ` (key below Escape)
  • Switch focus to a panel. To move keyboard focus to the taskbar: Ctrl + Alt + Tab
  • Cycle through panel elements. To move between different parts of a panel: Ctrl + Alt + Esc
  • Show the desktop. To minimize all windows at once: Ctrl + Alt + D
  • Switch workspace in a given direction. To move between virtual desktops: Ctrl + Alt + ↑ / ↓ / ← / →
  • Take a screenshot. To capture the entire screen: Print Screen
  • Take a window screenshot. To capture only the active window: Alt + Print Screen
  • Run command slot two. Often assigned to a region or selection screenshot: Shift + Print Screen
  • Run command slot seven. Often assigned to a task manager: Ctrl + Shift + Esc
  • Open a terminal. To get a shell quickly without using menus: Ctrl + Alt + T
  • Run command slot one. Often assigned to locking the screen: Super + L
  • Run command slot three. Custom assigned, often a file manager: Super + E
  • Run command slot four. Custom assigned: Super + T
  • Run command slot five. Custom assigned: Super + I
  • Run command slot six. Custom assigned: Super + S
  • Run command slot eight. The Pause key is rarely used elsewhere, making it a safe free slot for a custom command: Super + Pause

Marco Window Manager: Window-Specific Shortcuts

  • Open the window menu. For keyboard access to move, close, and other window actions: Alt + Space
  • Close the window. The standard close shortcut: Alt + F4
  • Begin moving the window. After pressing this, use arrow keys to move it: Alt + F7
  • Begin resizing the window. After pressing this, use arrow keys to resize it: Alt + F8
  • Minimize the window. Sends it to the taskbar: Alt + F9
  • Toggle maximize. To maximize or restore the window using the keyboard: Alt + F10
  • Toggle shade. Rolls the window up into just its titlebar, useful for briefly checking what's behind it: Ctrl + Alt + S
  • Move the window to center. To re-center a window that has drifted off-screen or is badly placed: Alt + Super + C
  • Maximize the window: Super + ↑
  • Restore the window to its previous size: Super + ↓
  • Tile the window to half the screen. For side-by-side work: Super + ← / →
  • Tile to the northwest corner, one quarter of the screen: Alt + Super + ←
  • Tile to the northeast corner: Alt + Super + →
  • Tile to the southwest corner: Shift + Alt + Super + ←
  • Tile to the southeast corner: Shift + Alt + Super + →
  • Move the entire window to the adjacent workspace in a given direction: Ctrl + Shift + Alt + ↑ / ↓ / ← / →

MATE Terminal Shortcuts

  • Open a new terminal window: Ctrl + Shift + N
  • Open a new tab in the same window. To keep sessions organized instead of opening many windows: Ctrl + Shift + T
  • Close the current tab: Ctrl + Shift + W
  • Close the entire terminal window, including all tabs: Ctrl + Shift + Q
  • Copy selected text. Plain Ctrl+C is reserved for interrupting a running process, so terminal copy uses this variant instead: Ctrl + Shift + C
  • Paste text. Same reasoning as copy above: Ctrl + Shift + V
  • Select all terminal text: Ctrl + Shift + A
  • Switch to the previous tab: Ctrl + Page Up
  • Switch to the next tab: Ctrl + Page Down
  • Move the current tab one position to the left: Ctrl + Shift + Page Up
  • Move the current tab one position to the right: Ctrl + Shift + Page Down
  • Switch directly to a tab by number, one through nine, or zero for the tenth tab: Alt + 1…9 or 0
  • Switch to the previous terminal profile, meaning a saved color and font scheme: Alt + Page Up
  • Switch to the next terminal profile: Alt + Page Down
  • Open find, to search terminal output: Ctrl + Shift + F
  • Find the next match: Ctrl + Shift + G
  • Find the previous match: Ctrl + Shift + H
  • Toggle full screen for a distraction-free terminal: F11
  • Open terminal help: F1
  • Zoom in, increasing font size: Ctrl + +
  • Zoom out, decreasing font size: Ctrl + -
  • Reset zoom to normal font size: Ctrl + 0

Tips for Building Muscle Memory

  1. Learn shortcuts in small batches. Trying to memorize all of these at once will not stick. Pick three to five that solve a problem you hit every day, and ignore the rest until those feel automatic.
  2. Start with the highest-value ones first. For most people that means: Alt+Tab to switch windows, Ctrl+Alt+T to open a terminal, Super+← or → to tile windows side by side, and Ctrl+Shift+T and Ctrl+Shift+W for terminal tabs. These get used dozens of times a day, so they pay off fastest.
  3. Force yourself to use the shortcut instead of the mouse. The temptation is always to reach for the mouse because it is faster in the moment. Muscle memory only forms when you deliberately choose the slower, correct path a few dozen times in a row. If you catch yourself reaching for the mouse, stop and use the key combination instead, even if it takes longer that time.
  4. Say the shortcut out loud, or describe it to yourself, as you press it. Verbalizing while doing reinforces the connection between the intention and the physical action faster than silent repetition.
  5. Practice in short, frequent bursts rather than one long session. Five minutes of deliberate practice a day for a week builds memory better than one thirty-minute drill.
  6. Chain related shortcuts together in one practice session. For example, practice opening a terminal, opening a new tab, switching between tabs, and closing a tab as one sequence. Grouping related actions together mirrors how you will actually use them in real work.
  7. Once one batch feels automatic, add the next batch. A shortcut feels automatic when you no longer have to think about which keys to press, your fingers just do it. That is the signal to introduce a new small set rather than trying to hold everything in mind simultaneously.
  8. Expect a temporary slowdown. For the first several days a new shortcut will feel slower than the mouse. This is normal and does not mean the shortcut is not worth learning. The payoff comes after the habit is formed, not during it.
