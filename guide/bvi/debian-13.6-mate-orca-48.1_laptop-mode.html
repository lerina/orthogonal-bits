Introduction — Three Positions

This guide describes three different ways of moving through text on a Debian 13.6 MATE desktop using Orca 48.1 in Laptop Mode.

The important idea is that there are three different positions to keep separate:

Caret = Write
The application's actual editing position.

Focus = Act
The currently active interface element.

Review = Look
Orca's Flat Review position, used to inspect what is displayed.

These positions can interact, but they are not the same thing.

MATE Terminal

Native Terminal Scrolling

These shortcuts move the terminal's visible viewport through its scrollback history.

They do not move the command-line editing cursor.

  • Scroll up one page. Shift + PageUp
  • Scroll down one page. Shift + PageDown
  • Scroll to the top of the terminal's scrollback history. Shift + Home
  • Return to the bottom of the terminal scrollback, near the current prompt. Shift + End

The terminal is changing what is displayed on screen. Orca's speech behavior depends on its terminal tracking and speech settings, so these shortcuts should be understood primarily as terminal scrolling commands.

Orca Laptop Mode Flat Review

Orca's Flat Review provides a temporary reading position over the content displayed on the screen.

In Laptop Mode, the Orca modifier is normally CapsLock.

Flat Review is useful when you want to inspect terminal output or other displayed text without deliberately moving the application's editing position.

Entering and Leaving Flat Review

  • Toggle Flat Review. This also refreshes the Flat Review context. CapsLock + P

Moving by Line

  • Move to the first line of the current Flat Review context. CapsLock + Ctrl + U
  • Move to the previous line. CapsLock + U
  • Read the current line. CapsLock + I
  • Move to the next line. CapsLock + O
  • Move to the last line of the current Flat Review context. CapsLock + Ctrl + O

Moving by Word

  • Move to the previous word. CapsLock + J
  • Read the current word. CapsLock + K
  • Move to the next word. CapsLock + L

Moving by Character

  • Move to the previous character. CapsLock + M
  • Read the current character. CapsLock + ,
  • Move to the next character. CapsLock + .

Flat Review moves Orca's review position. It does not deliberately move the application's text cursor.

This distinction is especially important when working in a terminal editor such as Helix.

Command-Line Editing

When Bash or another readline-based command line is active, these shortcuts move the actual command-line editing cursor.

  • Move to the beginning of the command line. Ctrl + A
  • Move to the end of the command line. Ctrl + E
  • Move backward by one word. Alt + B
  • Move forward by one word. Alt + F

These commands change where text will be inserted or edited.

They are therefore caret commands, not Flat Review commands.

Helix: The Rust Programmer's Editor

Helix is a modal text editor running inside the terminal.

There are two fundamentally different ways to navigate its displayed text:

  1. Use Helix navigation to move the actual Helix cursor.
  2. Use Orca Flat Review to inspect the terminal display without deliberately moving the Helix cursor.

Keeping these two operations separate prevents confusion about where text will actually be inserted.

Helix Normal Mode

Press Escape to ensure that Helix is in Normal Mode.

Helix's navigation commands move the actual editor cursor.

Basic Movement

  • Move left by one character. h
  • Move down by one line. j
  • Move up by one line. k
  • Move right by one character. l

The arrow keys can also be used for basic movement.

Word Movement

  • Move forward to the beginning of the next word. w
  • Move backward to the beginning of the previous word. b
  • Move to the end of the current word. e

These commands change the actual Helix editing position.

Helix Page and File Navigation

Page Movement

  • Move one page upward. Ctrl + B
  • Move one page downward. Ctrl + F
  • Move approximately half a page upward. Ctrl + U
  • Move approximately half a page downward. Ctrl + D

File Movement

  • Jump to the beginning of the file. g + g
  • Jump to the last line of the file. g + e

Current-Line Movement

  • Move to the beginning of the current line. g + h
  • Move to the end of the current line. g + l

These are Helix commands. They move the actual Helix cursor.

Orca and Helix

Helix does not expose its terminal text in exactly the same way as a conventional graphical text editor.

Helix draws its interface inside the terminal. Orca therefore interacts with the terminal's displayed content rather than treating the Helix buffer as a conventional graphical accessibility document.

As a result, Orca's speech behavior while moving the Helix cursor can depend on the terminal, Orca's settings, and how the terminal exposes its current contents.

For this reason, it is better to think of the two systems separately:

Helix controls the editing position.

Orca controls speech and Flat Review.

When Helix moves its cursor, Orca may announce the resulting terminal content according to its current settings.

Reading Without Moving the Helix Cursor

Suppose you are editing Rust code at one location but want to inspect another part of the visible screen.

Use Orca Flat Review.

Press:

CapsLock + P

Then use:

  • Previous line.CapsLock + U
  • Read current line.CapsLock + I
  • Next line.CapsLock + O
  • Previous word.CapsLock + J
  • Read current word.CapsLock + K
  • Next word.CapsLock + L
  • Previous character.CapsLock + M
  • Read current character.CapsLock + ,
  • Next character.CapsLock + .

This lets you inspect displayed text while keeping the Helix editing position separate.

The Important Helix Rule

If you use Flat Review to read a line of Rust code, the location you are reviewing is not automatically the location where Helix will insert text.

For example:

  • You are editing line 50.
  • You use Flat Review to inspect line 20.
  • You then leave Flat Review and begin typing.
  • Your typing still goes to the actual Helix cursor at line 50.

The Flat Review position does not automatically become the Helix cursor.

This is one of the most important distinctions to remember when using Orca with terminal editors.

Moving the Actual Helix Cursor

When you want to change the place where editing occurs, use Helix navigation.

For example:

  • Move between lines.j / k
  • Move between characters.h / l
  • Move between words.w / b / e
  • Go to the beginning of the file.g + g
  • Go to the last line.g + e
  • Go to the beginning of the current line.g + h
  • Go to the end of the current line.g + l
  • Move by pages.Ctrl + B / Ctrl + F
  • Move by half pages.Ctrl + U / Ctrl + D

These commands change the actual editing position.

Refreshing the Helix Display

Helix provides the :redraw command to redraw the entire interface.

If the terminal display appears incorrect, or Orca's Flat Review context appears to be based on an outdated screen, a redraw can help.

Press Escape to enter Normal Mode, then enter:

:redraw

Press Enter.

This forces Helix to repaint its interface.

:redraw should be considered a display-refresh command, not an Orca synchronization command.

The Three Positions

It helps to keep three concepts separate.

Caret = Write — the editing position

The caret is the actual editing position.

  • In Helix, this is the Helix cursor.
  • In a terminal command line, it is the command-line cursor.

Moving the caret changes where editing takes place.

Use Helix navigation or command-line editing commands when you need to change it.

Focus = Act — the interface element

Accessibility focus identifies the currently active interface object.

Examples include:

  • A button.
  • A menu item.
  • A list item.
  • A file in a file manager.
  • A control in a dialog.
  • A toolbar element.

Tab and Shift + Tab commonly move between interface controls.

Arrow keys commonly move within menus and lists.

Enter or Space activates the focused object when appropriate.

Focus is therefore about interacting with the user interface.

Think: Focus = Act

Review = Look — the reading position

Flat Review is Orca's temporary reading position.

It is useful for inspecting what is displayed on the screen.

Flat Review can move through lines, words, and characters without deliberately moving the application's editing position.

Think: Review = Look

The Practical Rule

When using Debian MATE with Orca and Helix, remember:

Caret = Write
Where will my next edit happen?
Use Helix navigation.

Focus = Act
Which interface element will respond to my next action?
Use accessibility focus navigation.

Review = Look
What text is currently displayed here?
Use Orca Flat Review.

The most important distinction is between looking at text and moving the editing position.

  • Orca Flat Review is for looking.
  • Helix navigation is for moving the editor.

Once these two operations become mentally separate, terminal-based editing becomes much easier to reason about.
