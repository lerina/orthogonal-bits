1. MATE Terminal

1.1 Copy and Paste

Ctrl+Shift+C Copy the selection Ctrl+Shift+V Paste

1.2 Tabs and Windows

Ctrl+Shift+T Open a new tab Ctrl+Shift+N Open a new terminal window Ctrl+Shift+W Close the current tab Ctrl+Shift+Q Close the window Ctrl+Page Up Switch to the previous tab Ctrl+Page Down Switch to the next tab Ctrl+Shift+Page Up Move the current tab left Ctrl+Shift+Page Down Move the current tab right

1.3 View

Ctrl++ Zoom in Ctrl+- Zoom out Ctrl+0 Reset zoom to normal F11 Toggle full screen Ctrl+Shift+F Find (confirm in the Search menu on your system, since this one varies by version) F1 Open MATE Terminal help

1.4 MATE Terminal Find

Ctrl+Shift+F opens Find in most GTK‑based terminals including MATE Terminal.

1.5 Bash Line Editing (Readline)

These shortcuts come from Bash, not MATE Terminal itself, but they matter for the same workflow. They work at any Bash prompt, whether you are in MATE Terminal, over SSH, or anywhere else Bash is running.

Moving the cursor

Ctrl+A Move to the start of the line Ctrl+E Move to the end of the line Ctrl+B Move back one character Ctrl+F Move forward one character Alt+B Move back one word Alt+F Move forward one word

Deleting and recovering text

Ctrl+U Delete everything from the cursor back to the start of the line Ctrl+K Delete everything from the cursor forward to the end of the line Ctrl+W Delete the word before the cursor Alt+D Delete the word after the cursor Ctrl+Y Paste back the last thing you deleted with Ctrl+U, Ctrl+K, Ctrl+W, or Alt+D

Command history

Ctrl+R Search backward through your command history as you type Ctrl+G Cancel a history search and return to an empty prompt ↑ or Ctrl+P Recall the previous command ↓ or Ctrl+N Recall the next command

Process and screen control

Ctrl+C Interrupt (kill) the currently running command Ctrl+Z Suspend the currently running command (resume later with fg) Ctrl+D On an empty line, logs you out or closes the terminal tab. On a line with text, deletes the character under the cursor instead. Ctrl+L Clear the screen without affecting your command history

Completion

Tab Autocomplete a command or file name Tab Tab If the first Tab does not complete uniquely, pressing it again lists the possible matches

💡 Tip: Put stty -ixon in your .bashrc so you can use Ctrl+S without freezing the terminal.

Caps Lock+Ctrl+U Jump to the top line visible on screen Caps Lock+U Move up one line Caps Lock+I Re‑read the current line Caps Lock+O Move down one line Caps Lock+J Review the previous word Caps Lock+K Re‑read the current word Caps Lock+L Review the next word Caps Lock+M Review the previous character Caps Lock+, Re‑read the current character Caps Lock+. 3. HELIX

3.1 Modes

I Enter insert mode Esc Return to normal mode (always safe)

3.2 Save and Quit

: W Save : Q Quit (only if there are no unsaved changes) : W Q Save and quit : Q ! Quit without saving

3.3 Undo and Redo

U Undo Shift+U (capital U) Redo

3.4 Basic Movement

H Left J Down K Up L Right W Select to next word start B Select to previous word start E Select to end of current word F + char Select up to and including that character (not confined to the current line) T + char Select up to but not including that character

3.5 Goto Menu

Press G then a second key.

G G Start of file G E End of file G H Start of the current line G L End of the current line G D Go to definition (needs rust‑analyzer)

3.6 Scrolling

Ctrl+B Page up Ctrl+F Page down Ctrl+U Half page up Ctrl+D Half page down

3.7 Editing

Select first, then act.

D Delete the selection Y Yank (copy) the selection P Paste after Shift+P Paste before C Change the selection (deletes and enters insert mode) R Replace the selection with one typed character X Select the current line (repeat to extend to more lines) % Select the entire file

3.8 Space Menu

Press Space then a key.

Space F File picker Space B Buffer picker Space / Global search across the project Space K Hover documentation Space A Code actions Space S Symbol picker

3.9 Multiple Cursors

Make a selection first, then press Shift+C (capital C) to copy that selection onto the line below and add a cursor there. Press C again to keep stacking cursors downward.

Shift+C Copy selection onto the line below and add a cursor (press again to stack downward) Alt+Shift+C Same thing but upward

To edit every match of a term inside a chosen scope, select the scope first (e.g. the whole file with %), then press S and type the pattern. This sub‑selects every match inside your selection so you can edit them together.

3.10 View Mode

Z Z or Z C Center the current line in the view (two keys for the same action) Z T Move the current line to the top of the screen Z B Move the current line to the bottom of the screen

3.11 Window Splits

Ctrl+W V Vertical split Ctrl+W S Horizontal split (not Ctrl+W H — that moves focus left) Ctrl+W W Cycle to the next split Ctrl+W + ← → ↑ ↓ Move focus to the split in that direction Ctrl+W Q Close the current split

3.12 Search Inside the File

/ Search forward ? Search backward N Next match Shift+N Previous match Esc Clear the search highlight

4. The Jump List in Helix

The jump list is an automatic trail of breadcrumbs. It records exactly where your cursor has been, allowing you to hop back and forth between different lines or even different files without losing your place.

How the Jump List Grows

Helix automatically saves a "jump point" to the list whenever you make a major movement. These movements include:

  • Searching for a word using /
  • Jumping to the top or bottom of a file using gg or ge
  • Jumping to a specific line using : followed by a line number
  • Manually dropping a pin using Ctrl+S (which you just freed up!)

🚀 The Core Shortcuts

Once Helix tracks your movements, use these commands in Normal Mode to travel along your history trail:

Ctrl+O Jump backward to your previous location (older) Ctrl+I Jump forward to your next location (newer) Space J Open the visual Jump List Picker

🦉 Using the Jump List with Orca

The Jump List Picker is highly accessible for screen reader users. When you press Space J, a small menu opens at the bottom of the screen showing your entire jump history.

  1. Press Space J to open the list.
  2. Use ↑ and ↓ to move through your saved points. Orca will read the line number and the snippet of text at that location.
  3. Press Enter to snap instantly to that file and line.
  4. Press Esc if you change your mind and want to close the picker without moving.

Clearing the Jump List

To clear the jump list when it gets too cluttered, use the :jclear (jump clear) command.

  1. Ensure you are in Normal Mode by pressing Esc.
  2. Type the command: :jclear
  3. Press Enter.

This instantly wipes out your entire jump history for the current session. Pressing Ctrl+O or Ctrl+I right after will do nothing until you start making new jumps or dropping fresh pins with Ctrl+S.

5. Buffer Management in Helix

To quickly switch between multiple open files (called "buffers") in Helix, you use the Buffer Picker or the next/previous shortcut commands in Normal Mode.

🥞 Method 1: The Buffer Picker (Most Visual & Screen‑Reader Friendly)

If you have several files open, you can view them all in an interactive list.

  1. Press Space B.
  2. A menu opens at the bottom listing all open files.
  3. Use ↑ and ↓ to cycle through the files. Orca will read the file names out loud as you move.
  4. Press Enter to open the selected file.

⏭️ Method 2: Fast Cycle Shortcuts (Fastest)

If you only have two or three files open, you can cycle through them instantly with single keystrokes without opening a menu.

] B Switch to the next open file [ B Switch to the previous open file

🚪 Method 3: Closing a File

When you are done with a file and want to remove it from your active list:

  1. Type :bc (buffer close) and press Enter.
  2. Helix will close that specific file and automatically snap your view to the next open buffer.

6. One‑Liner for Quick Inspection

To fetch a web page and obtain clean, well‑structured Markdown output, run:

obscura fetch "https://docs.rs/topcoat/latest/topcoat/" --dump markdown > guide.md

If you only need to read the page without saving a file, you can pipe the output directly to less or to Helix's standard input:

obscura fetch "https://docs.rs/topcoat/latest/topcoat/" --dump markdown | less

Or, if you prefer to open it in Helix immediately without creating a permanent file:

obscura fetch "https://docs.rs/topcoat/latest/topcoat/" --dump markdown | hx -

The - argument tells Helix to read from standard input. This is useful for quick lookups.
