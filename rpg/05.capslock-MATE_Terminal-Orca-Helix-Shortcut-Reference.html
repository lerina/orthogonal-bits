Helix — Selection & Editing

Selection and editing commands
ShortcutAction
xSelect the current line.
XExtend the selection to the line boundaries.
%Select the entire file.
dDelete the selection.
yYank the selection.
pPaste after.
PPaste before.
cChange the selection.
rReplace with one character.
CCopy the selection to the next line and add a cursor.

Regex selection

Regex-based selection
ShortcutAction
sSelect all regex matches inside the current selection.
SSplit the selection on regex matches.

Example: select the entire file with %, press s, enter a regex — every match becomes a selection.

PART 3, CONTINUED

Helix — Jump List & Workflow

Jump list commands
ShortcutAction
Ctrl+SSave the current selection as a jump.
Ctrl+OJump backward.
Ctrl+IJump forward.
Space jOpen the jump list picker.

The jump list records significant movements: searches, large file movements, definition/reference jumps, buffer changes, and manual Ctrl+S jumps.

Search-and-navigation workflow

/

Find something.

n

Move to the next occurrence.

g d

Go to its definition.

g r

Go to its references.

Ctrl+O

Return to the previous location.

Ctrl+I

Move forward again.

Space j

Inspect the jump history.
