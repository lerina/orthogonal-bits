CHAPTER 01

THE SIX-OUTCOME
CORE ENGINE

One randomizer. One table. Everything in this edition — combat, hacking, conversation, oracles — resolves off the same six-shade read instead of a simple three-band pass/fail.

THE RANDOMIZER

The Digit-Sum Draw

Still nothing but a clock. The difference in this edition is what you do with the result once you have it.

01

State the action, set a Difficulty

Easy / Medium / Hard — a narrative lever, not a probability you calculate by hand.

02

Check a clock

Take the current second (0–59) and add its two digits together.

03

Reduce to one digit

:47 → 4+7=11 → 1+1=2. Keep summing until a single digit (0–9) remains.

04

Convert to a D6, then read the outcome

Two lookups, both below. No clock on hand? The Pulse Draw (heartbeat count, same reduction) works identically.

Difficulty shift: Easy shifts the outcome one step toward "Yes, and." Hard shifts one step toward "No, and." Medium — read the table as-is. Any Style-like trait from Chapter 02 stacks as an extra Easy-tier shift on top.

WHY ONE TABLE FOR EVERYTHING

Base Game vs. Extended Engine

The base rulebook reads the clock straight into three bands — a fast, minimal read built for the Rule of Three. Extended Edition keeps the exact same physical action (glance at a clock) but routes it through the full digit-sum pipeline, so every draw carries six shades of consequence instead of three.

BASE GAME

Raw second → 3 bands

:00–:19 / :20–:39 / :40–:59 compared straight to Difficulty. Fast, minimal, built for a one-breath character.

EXTENDED EDITION

Digit-sum → D6 → 6 outcomes

Same clock, more resolution. Every draw is hat-shaped, not flat — extremes are rarer and land harder.

NO SEPARATE SUBSYSTEMS

One Engine, Every Situation

Nothing in this edition gets its own dice mechanic. Combat, netrunning, and conversation all read off the same six-outcome table — only the fictional consequence attached to each result changes.

PHYSICAL

Combat & movement

A "No, and" doesn't add a damage number — it Glitches your Gear or escalates the Adversary, same as the base game.

DIGITAL

Netrunning

A "Yes, but" on a dive still costs what your Rig's flavor says it costs — loud, slow, or physical feedback.

SOCIAL

Conversation & persuasion

A "Yes, and" on a Face's pitch might mean the NPC volunteers something you didn't even ask for.

The table never changes. Only the sentence you attach to each result does — that's the whole reason one engine can carry an entire session.
GENERATING THE DIGIT

Duet Mode & the Pulse Draw

Duet Mode (optional, 2 players): instead of a clock, the second person silently picks a digit 0–9 and reveals it the moment the action is stated. It runs through the exact same D6 and outcome tables above — nothing else changes.

Pulse Draw (no clock): count heartbeats from the moment you state the action until you silently think "now." Add the digits of that count together until one remains. Same pipeline, no clock required.

Example: Difficulty called Hard. Digit-Sum Draw produces digit 7 → D6 of 5 → base outcome "No." Hard shifts one step further → "No, and." The guard doesn't just stop you — the alarm goes up.
