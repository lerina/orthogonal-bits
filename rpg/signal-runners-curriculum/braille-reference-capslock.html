WHY THIS CARD EXISTS

Reading Code Under the Fingertips

A Braille Matrix doesn't render syntax highlighting. It refreshes raised dots against the skin, cell by cell, and the operator a hand reads under the first two fingers has to be exactly as unambiguous as the character it represents — no color, no font weight, nothing but geometry to tell an assignment from an equality check. This card is the cell layout every Signal Runner eventually has memorized cold: the standard alphabet first, then the symbol set that actually matters once the alphabet stops being the hard part and Rust's own punctuation starts.

THE ONE MISTAKE THAT COSTS A JOB

Similar Dots, Different Cells

g VS = The letter g (⠛, dots 1-2-4-5) is not the same as = (⠨⠅, dots 4-6 then 1-3) — even though both involve overlapping dot numbers, they are built from a different number of cells entirely.

g is a single cell: dots 1-2-4-5, read in one contact.

= is two cells, read as a sequence: the first cell is dots 4-6, the second cell is dots 1-3. Reading speed hides this difference fast — rushed fingers can blur a two-cell operator into something that feels like a single letter. Slow down on anything that starts with dots 4-6 until the second cell confirms what's actually there.
